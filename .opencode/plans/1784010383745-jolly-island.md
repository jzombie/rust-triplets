# Plan: Eliminate String Cloning Overhead in AoS Pipeline

## Problem

`SplitState::step()` in `crates/triplets-offline-embedder/src/split_state.rs` **clones every string** when moving from `SamplerBatch` to `PendingState`. The `batch` is consumed by value, so strings can be **moved** — but the current chunking loop borrows `&entries[chunk_start..chunk_end]`, preventing moves.

Additionally, the `accumulate` function (line 134) only handles pairs, with a TODO acknowledging this is confusing. It should be deleted — `step()` already handles both modes directly.

## Cloning Hotspots to Eliminate

| Line | Current (clone) | Target (move) |
|---|---|---|
| 269 | `entry.anchor_text.clone()` | `entry.anchor_text` |
| 271 | `entry.candidate_text.clone()` | `entry.candidate_text` |
| 333 | `chunk[i].anchor_text.clone()` | `entry.anchor_text` |
| 335 | `chunk[i].pos_text.clone()` | `entry.pos_text` |
| 337 | `chunk[i].neg_text.clone()` | `entry.neg_text` |

**Cannot eliminate:** Embedding vector clones (`embedded[map[i]].clone()`) — dedup reuses vectors across entries, requiring clones. Parity with any implementation.

## Refactoring: Two-Phase Execution Model

Separate the **borrow phase** (embedding, needs `&str` references) from the **consume phase** (assembly, moves `String` values).

### Step 1: Pair Path — Two-Phase Execution

**File:** `crates/triplets-offline-embedder/src/split_state.rs` (lines 199–279)

```rust
SamplerBatch::Pairs(entries) => {
    let mut all_anchor_vecs = Vec::with_capacity(entries.len());
    let mut all_candidate_vecs: Vec<Option<Vec<f32>>> = Vec::with_capacity(entries.len());

    // Phase 1: Borrow and Embed (entries untouched)
    for chunk in entries.chunks(chunk_size) {
        let anchor_refs: Vec<&str> = chunk.iter().map(|e| e.anchor_text.as_str()).collect();
        let anchor_vecs = match embedder.embed(&anchor_refs) { /* ... */ };
        // ... validation, dedup, candidate embedding ...
        all_anchor_vecs.extend(anchor_vecs);
        for (i, entry) in chunk.iter().enumerate() {
            if entry.candidate_text == entry.anchor_text {
                all_candidate_vecs.push(None);
            } else {
                all_candidate_vecs.push(Some(candidate_embs[candidate_indices[i]].clone()));
            }
        }
    }

    // Phase 2: Consume and Assemble (zero-copy string moves)
    for (entry, (a_vec, c_vec_opt)) in entries.into_iter()
        .zip(all_anchor_vecs.into_iter().zip(all_candidate_vecs.into_iter()))
    {
        // Resolve clone BEFORE moving a_vec into the struct
        let final_c_vec = c_vec_opt.unwrap_or_else(|| a_vec.clone());

        self.pending.push_pair(PendingPair {
            anchor_text: entry.anchor_text,       // MOVED
            anchor_vec: a_vec,                    // MOVED
            candidate_text: entry.candidate_text,  // MOVED
            candidate_vec: final_c_vec,            // MOVED
            label: entry.label,
        });
    }
}
```

### Step 2: Triplet Path — Two-Phase Execution

**File:** `crates/triplets-offline-embedder/src/split_state.rs` (lines 281–345)

Same structural separation. Accumulate `all_anchor_vecs`, `all_pos_vecs`, `all_neg_vecs` during the borrowed `chunks(chunk_size)` loop. Consume `entries.into_iter()` only after all embedding completes.

Critical: resolve `pos_vec` and `neg_vec` deduplication fallback clones **before** assigning `anchor_vec` into the struct — never inline within the struct literal if the anchor vector is declared above it.

```rust
SamplerBatch::Triplets(entries) => {
    let mut all_anchor_vecs = Vec::with_capacity(entries.len());
    let mut all_pos_vecs = Vec::with_capacity(entries.len());
    let mut all_neg_vecs = Vec::with_capacity(entries.len());

    // Phase 1: Borrow and Embed
    for chunk in entries.chunks(chunk_size) {
        // ... build unique_texts, embed, dedup ...
        all_anchor_vecs.extend(chunk.iter().map(|e| embedded[anchor_map[i]].clone()));
        all_pos_vecs.extend(/* ... */);
        all_neg_vecs.extend(/* ... */);
    }

    // Phase 2: Consume and Assemble
    for (entry, (a_vec, (p_vec, n_vec))) in entries.into_iter()
        .zip(all_anchor_vecs.into_iter()
            .zip(all_pos_vecs.into_iter().zip(all_neg_vecs.into_iter())))

}
```

### Step 4: Add `push_pair` and `push_triplet` Helpers with Safety

Add convenience methods to `PendingState` with `unreachable!()` to catch state desynchronization:

```rust
impl PendingState {
    pub fn push_pair(&mut self, entry: PendingPair) {
        if let PendingState::Pairs(v) = self {
            v.push(entry);
        } else {
            unreachable!("push_pair called on Triplets state");
        }
    }
    pub fn push_triplet(&mut self, entry: PendingTriplet) {
        if let PendingState::Triplets(v) = self {
            v.push(entry);
        } else {
            unreachable!("push_triplet called on Pairs state");
        }
    }
}
```
