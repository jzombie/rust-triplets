# Plan v6: Per-Batch Negative Uniqueness (AMEND-4 applied)

## 0. Disposition
v5 fixed guard bifurcation, `nohash-hasher`, negative-only retries. AMEND-4 fixes: (1) swap-inside-loop borrow/move + clone churn, (2) dropped `triplet_chunk_weight`. Restructure below; all else retained.

## 1. Scope / key / set / commit (unchanged)
- Option A only. Key `neg_h = stable_hash_str(0, &chunk.text)`; `nohash_hasher::IntSet<u64>` only. Atomic check-then-commit retained.

## 2. Ownership-safe retry structure (fixes SEV-1 + SEV-2)
Per candidate (serial split + parallel Phase-3), in this exact order:

1. **Draw anchor + positive once** (`select_anchor_positive_for_recipe` / `SlotCandidate`).
2. **Hoist coin-flip swap once, before retries.** Consume the drawn pair into `final_anchor`, `final_positive` (one move, no loop):
```rust
let (final_anchor, final_positive) = if rng.next_u64() & ANCHOR_POSITIVE_SWAP_MASK == 0 {
    (positive_chunk, anchor_chunk)
} else {
    (anchor_chunk, positive_chunk)
};
```
   - RNG draw happens once here (preserves existing swap distribution; sequential `rng` in Phase-3 / serial paths keeps determinism).
3. **Guard (A) on finalized values, before loop:**
```rust
if !recipe.allow_same_anchor_positive && final_anchor.text == final_positive.text {
    continue; // outer — unrecoverable
}
```
4. **Open `NEG_DEDUP_RETRIES = 4` loop — references only:**
   - Draw `neg_chunk` (owned fresh each iteration: `select_negative_record` + `select_chunk`/`select_chunk_parallel` + decorate).
   - Evaluate by reference only — `&final_anchor`, `&final_positive`, `&neg_chunk`: build `key` via `RecordKey::of_chunk(&...)`, `neg_h` via `negative_text_hash(&neg_chunk)`, (B) checks `neg.text == final_pos.text || neg.text == final_anchor.text`, `!seen.contains(&key)`, `!seen_negatives.contains(&neg_h)`. **No `.clone()` of anchor/positive inside the loop.**
   - On pass: compute weight **by reference** (restores dropped math):
```rust
let chunk_weight = self.triplet_chunk_weight(&recipe, &final_anchor, &final_positive, &neg_chunk);
let weight = recipe.weight * chunk_weight;
```
   - Then **defer consumption to commit**: move `final_anchor`, `final_positive`, `neg_chunk` into `SampleTriplet { recipe, anchor: final_anchor, positive: final_positive, negative: neg_chunk, weight, instruction }`, insert `seen` + `seen_negatives`, `push`, `break`. Because the move is followed immediately by `break`, the borrow checker accepts reuse of the names across retry iterations (each iteration either moves-and-breaks or borrows-and-continues; failed iterations drop only `neg_chunk`).
   - Failed iterations drop `neg_chunk` at end of iteration; `final_*` stay alive by borrow, not move.
5. Exhaust retries → `continue` outer `attempts` (skip slot).

Why this fixes the flaws: swap executes once (no moved-value-in-loop error, no per-retry clones); weight math (`triplet_chunk_weight` over all three chunks × `recipe.weight`, incl. `fallback_same_split` naming) is restored exactly as `make_triplet_with_anchor`/`finalize` did; retry loop is pure-negative with zero anchor/positive alloc churn.
